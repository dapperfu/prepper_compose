Local only

A library that stays up when the internet does not.

Reference books, repair guides, medical articles, street maps, and a few small tools, served from this machine to every phone and laptop on the same network.

Open this address on another device: http://localhost:8888

The first start downloads the full archives onto disk: English Wikipedia and Wikibooks with pictures, wikiHow, iFixit, and the full English Project Gutenberg. They are not stored inside the Docker image. Licensed Prepper Disk books are not included. Put your own legal copies in Files.
